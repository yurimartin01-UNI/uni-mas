01

Qué es UNI+

UNI+ es un plugin para Moodle que apoya al cuerpo docente en el seguimiento estudiantil. Consolida indicadores objetivos calculados a partir de los registros nativos del LMS y los presenta en un panel donde el docente puede observar la trayectoria de cada estudiante y recibir sugerencias pedagógicas generadas con asistencia de un modelo de lenguaje.

El proyecto se desarrolla en el marco del piloto interuniversitario coordinado por SEGIB en el Lab UniversitarIA, con participación de UTEC y UBA durante el período mayo–agosto 2026.

Qué hace

  • Consolida actividad, rendimiento y entregas por estudiante.
  • Calcula un Índice de Seguimiento (IS) que resume la trayectoria.
  • Clasifica patrones en niveles de prioridad de atención.
  • Genera sugerencias pedagógicas con asistencia de un modelo de lenguaje.
  • Registra las acciones e intervenciones que el docente decide.

Qué no hace

  • No toma decisiones automáticas.
  • No predice deserción ni asigna scores individuales de riesgo.
  • No reemplaza el criterio docente.
  • No utiliza datos sensibles por restricción explícita del diseño.

03

Arquitectura

UNI+ es un plugin local de Moodle. Se instala en moodle/local/unimas y se ejecuta dentro de la propia infraestructura institucional. Los componentes principales se relacionan así:

Moodle
LMS institucional · datos nativos del curso
↓
Plugin UNI+ (local_unimas)
PHP · JS · CSS dentro de Moodle
↓
Procesamiento de indicadores
Cálculo del IS · actividad, rendimiento, entregas
Integración IA configurable
Proveedor externo · gateway institucional · modelo local
↓
Panel docente
Visualización · sugerencias · registro de acciones

Backend

PHP, siguiendo la arquitectura estándar de plugins Moodle. Capabilities, settings administrativos y scheduled tasks gestionados desde la propia plataforma.

Frontend

HTML, CSS y JavaScript vanilla. SheetJS local para procesamiento de archivos Excel del lado del cliente.

Integración con IA

Compatible con endpoints tipo OpenAI (Gemini, OpenAI, Anthropic, DeepSeek), gateway institucional o modelo local self-hosted. Lista blanca de dominios configurada en el plugin.

05

Protección de datos

El diseño del plugin incorpora consideraciones de protección de datos desde el inicio. El cumplimiento legal final depende de las definiciones institucionales de cada universidad participante.

Minimización

Solo se transmiten al modelo de IA los datos estrictamente necesarios para generar las sugerencias. No se envían identificadores personales ni datos sensibles.

Restricción explícita

Por diseño, el sistema no utiliza datos de género, renta, raza, religión, salud ni otras categorías sensibles.

Integración configurable

El plugin soporta proveedor externo, gateway institucional o modelo local self-hosted. La elección depende de la política de cada institución.

Lista blanca de endpoints

El plugin valida que las URLs de IA configuradas pertenezcan a dominios previamente aprobados.

Acceso restringido

El panel docente requiere capability propia (local/unimas:view) asignada a docentes y gestores del curso. Las acciones se protegen mediante verificación de token de sesión.

Marco normativo

Toma como referencia la Ley 18.331 y el Decreto 64/020 (Uruguay), y la Ley 25.326 y normativa complementaria de la AAIP (Argentina).

Esta sección describe el diseño técnico del plugin en materia de datos. No constituye una declaración de cumplimiento legal definitivo. La verificación final corresponde a cada institución según su marco normativo aplicable.

06·1

Instalación

UNI+ se instala como cualquier plugin local de Moodle. Requiere acceso de administración del sitio.

  1. 1. Obtener el código

    Clonar el repositorio o descargar la versión más reciente:

    git clone https://github.com/yurimartin01-UNI/uni-mas.git

  2. 2. Copiar el plugin a Moodle

    Colocar la carpeta unimas dentro del directorio local/ de la instalación de Moodle.

    cp -r uni-mas/unimas /ruta/a/moodle/local/

    La ruta final debe ser moodle/local/unimas.

  3. 3. Completar la instalación desde Moodle

    Acceder como administrador y dirigirse a Administración del sitio → Notificaciones. Moodle detectará el plugin y aplicará las tablas correspondientes a la base de datos.

  4. 4. Configurar la integración con IA

    En la configuración del plugin, seleccionar el proveedor (Gemini, OpenAI, Anthropic Claude, DeepSeek o endpoint personalizado) y registrar la API key correspondiente.

  5. 5. Asignar permisos

    El plugin define la capability local/unimas:view, otorgada por defecto a los roles editingteacher y manager.

Requisitos técnicos
  • Moodle 4.1 LTS o superior.
  • PHP 8.1 o superior.
  • Base de datos compatible con Moodle (PostgreSQL, MySQL, MariaDB).
  • Extensiones PHP: curl, json, mbstring.
  • Conectividad saliente hacia el proveedor de IA configurado.
